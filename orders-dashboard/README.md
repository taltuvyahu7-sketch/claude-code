# INN7fashion — דשבורד הזמנות (שופיפיי + ג'ימייל)

דשבורד מתעדכן שמציג את 50 ההזמנות האחרונות של החנות inn7fashion.com לצד הודעות
לקוחות שמגיעות לג'ימייל (tal.t@inn7-fashion.com, בעיקר התראות Shopify Inbox).

## מה יש בו

- **KPI** — סך הזמנות, הכנסות נטו, ממתינות לשילוח, בעיות פתוחות, הודעות ללא מענה, אבדן מביטולי מלאי.
- **דורש טיפול עכשיו** — התראות ממוינות לפי דחיפות (תלונות, הזמנות ששולמו ולא נשלחו,
  תשלומים שממתינים לגבייה, משלוחים מעוכבים, ביטולי מלאי, הזדמנויות מכירה).
- **טבלת הזמנות** — סטטוס תשלום ומשלוח לכל הזמנה, קישורי מעקב (DHL/FedEx), ותגיות בעיה.
  כולל סינון (דורש טיפול / בדרך / נמסר / בוטל) וחיפוש.
- **פירוט הזמנה בלחיצה** — לחיצה על שורה פותחת את פירוט הפריטים: מחיר רגיל, אחוז/סכום
  הנחה (כולל קוד קופון ברמת ההזמנה), מחיר ששולם לפריט, סה"כ לשורה, משלוח והחזרים.
- **עלות ורווח (COGS)** — לכל פריט מוצגת העלות שמוזנת בשופיפיי (Cost per item) והרווח
  לשורה; בסיכום ההזמנה: עלות סחורה כוללת ורווח גולמי באחוזים (אחרי הנחות והחזרים,
  ללא משלוח). KPI "רווח גולמי משוער" מסכם את כל ההזמנות ששולמו. פריטים ללא עלות
  מוזנת מסומנים "לא מוזן"; עלות 0 מסומנת ⚠.
- **סימון "טופל ✓"** — על כל התראה והודעת לקוח. הסימון נשמר ב-localStorage של הדפדפן,
  שורד רענוני נתונים, וניתן לביטול ("החזר ↩") דרך "הצג N שטופלו".
- **מכירות יומיות** — גרף הכנסות ל־20 הימים האחרונים.
- **הודעות לקוחות ללא מענה** — מהג'ימייל, עם קישור להזמנה הרלוונטית כשיש.

## איך זה מתעדכן

- הקובץ `dashboard.html` מכיל את הנתונים מוטמעים (נבנה מחדש בכל רענון).
- מפורסם כ־Artifact בכתובת קבועה: https://claude.ai/code/artifact/ca750a53-5ea5-4b2d-83e5-673cd88153cc
- Routine בשם "רענון דשבורד הזמנות INN7" רץ כל 6 שעות: מושך הזמנות טריות משופיפיי
  (GraphQL Admin API), סורק את הג'ימייל להודעות לקוחות חדשות, מעדכן את הקובץ,
  מפרסם מחדש לאותה כתובת, ודוחף לענף הזה.

## עלויות שילוח בפועל (DHL/FedEx)

- הקובץ `shipping-costs.json` ממפה מספר מעקב (AWB) → עלות בש"ח, מתוך חשבוניות המוביל.
- הגישה הישירה ל-DHL MyBill חסומה ממדיניות הרשת של הסביבה, ומיילי החשבוניות מכילים
  רק סכום כולל (הפירוט בקובץ PDF מצורף שחיבור הג'ימייל לא מאפשר להוריד).
- הזרימה האוטומטית: סקריפט Google Apps Script‏ (`apps-script/save-invoices.gs`) שומר כל
  שעה את קבצי החשבוניות מהמייל לתיקיית Drive בשם "DHL Invoices"; הרענון המתוזמן סורק
  את התיקייה דרך חיבור Google Drive, מחלץ עלות לכל AWB וממלא את הקובץ.
- אפשר גם ידנית: להעלות לצ'אט CSV מ-MyBill (או PDF) וקלוד יקלוט.
- כשקיימת עלות למשלוח, פירוט ההזמנה מציג "עלות שילוח בפועל" ו"רווח נטו אחרי שילוח"
  (המרה לפי `rateIlsPerEur`).

## מקורות נתונים

| מקור | מה נמשך |
|---|---|
| Shopify Admin GraphQL | הזמנות: סטטוס תשלום/שילוח, ביטולים וסיבתם, החזרים, מעקב משלוחים, פריטים |
| Gmail | הודעות Shopify Inbox‏ (`from:no-reply@mailer.shopify.com`), מיילים של DHL/FedEx ולקוחות |

## זיהוי בעיות (הלוגיקה)

| בעיה | תנאי |
|---|---|
| לגבות תשלום ולשלוח | `AUTHORIZED` ולא בוטלה |
| שולם ולא נשלח | `PAID` + `UNFULFILLED`; קריטי אחרי 3 ימים |
| משלוח מעוכב / מסירה נכשלה | `DELAYED` / `ATTEMPTED_DELIVERY` באחד המשלוחים |
| בוטל — חוסר מלאי | `cancelReason = INVENTORY` (איתות לבעיית סנכרון מלאי) |
| החזר חלקי | `PARTIALLY_REFUNDED` |
| תלונה / הזדמנות | הצלבה ידנית של הודעות ג'ימייל להזמנות |
